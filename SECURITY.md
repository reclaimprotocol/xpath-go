# Security Policy

## Supported versions

Security fixes are assessed for the latest released `1.x` version of
xpath-go. Older releases may receive guidance, but are not guaranteed to
receive patches.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[admin@reclaimprotocol.org](mailto:admin@reclaimprotocol.org). Do not open a
public GitHub issue, pull request, or discussion for an unpatched
vulnerability.

Include, where possible:

- the affected version or commit;
- a minimal reproduction or proof of concept;
- impact and the conditions required to exploit it; and
- any suggested remediation or disclosure deadline.

Avoid accessing data that does not belong to you, disrupting services, or
expanding testing beyond what is needed to demonstrate the issue. The report
will be handled under the [Reclaim Protocol security
policy](https://github.com/reclaimprotocol/.github/blob/main/SECURITY.md).

## Disclosure

Please allow maintainers time to investigate and coordinate a fix before
public disclosure. If a fix is released, maintainers may publish an advisory,
release note, or changelog entry and will coordinate credit when requested.
