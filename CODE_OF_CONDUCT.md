# Code of Conduct

xpath-go follows the [Reclaim Protocol Code of
Conduct](https://github.com/reclaimprotocol/.github/blob/main/Code-of-Conduct.md).
It applies to this repository’s issues, pull requests, reviews, and other
project spaces.

Please report conduct concerns privately to
[conduct@reclaimprotocol.org](mailto:conduct@reclaimprotocol.org). Do not
report conduct concerns in a public issue. Reports are handled under the
organization policy, including its confidentiality and anti-retaliation
expectations.
