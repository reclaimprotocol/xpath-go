# Support

Start with the resource that best matches your need:

| Need | Where to start |
| --- | --- |
| Installation and basic use | [README](README.md) |
| Public API and option behavior | [API reference](docs/API.md) |
| Supported XPath/HTML behavior | [Compatibility scope](docs/COMPATIBILITY.md) |
| Testing or contributing | [Contributing guide](CONTRIBUTING.md) and [testing guide](docs/TESTING.md) |
| Reproducible defect | [Bug report](https://github.com/reclaimprotocol/xpath-go/issues/new/choose) |
| New capability or API proposal | [Feature request](https://github.com/reclaimprotocol/xpath-go/issues/new/choose) |
| Security concern | [Security policy](SECURITY.md) |

When opening an issue, include the xpath expression, a minimal input document,
the actual and expected result, the xpath-go version, and the Go version. Do
not include secrets, production data, or unredacted credentials.

GitHub Discussions are not enabled for this repository. The issue forms are
therefore the public channel for reproducible bugs, feature proposals, and
questions that may improve the documentation.
